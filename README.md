# About

t3D (Term3D) is a game engine for python that runs, plays, and works in the terminal.

t3D can also show the game inside a window, but its not recommended as its in beta, its for testing, and NOT the point of the game engine.

# Why I made this

I made this because I wanted to make a 3D game engine, and I wanted to make a game engine that felt like a old, low-quality game engine like idtech.

Also I made it because I wanted to learn some rendering, and I made it because I'm planning to make a tool to make t3D games easier that compile to a .py file.
